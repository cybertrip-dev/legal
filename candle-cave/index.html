Candle Cave — Support

Thanks for playing Candle Cave, a one-finger cave runner about spending light to see. Pressing jumps — and the same hand covers the candle, so the moment you commit to a jump you stop being able to see. Letting go opens the light and shows you a second or so of cave ahead, but the wax burns down while it is open and moths steer toward the flame. Wax is the light: as it drains the visible circle shrinks, so a bad run gets darker exactly when it needs to get brighter. Wax pools on the floor can only be picked up while running, wall lanterns only while jumping, and later caves place them in the same stretch so the two demands collide.

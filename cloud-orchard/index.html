Cloud Orchard — Support

Thanks for playing Cloud Orchard, a merge puzzle with a second verb. Merging clouds is only half of it: tapping any cloud of fleece size or larger turns it into rain that falls down its own column, melting the frost it passes, leaving dew on the cells it empties, and scoring the seedbed below only if it reaches the bottom row. Frost can never be merged away — rain is the only thing that removes it — and rain always vacates the cell it fell from, so a sky with even one fleece left in it can never deadlock. Where you build a cloud matters as much as how big you build it, because a fleece reaches two rows down, a cumulus four, and a rainbow to the foot of its column plus the columns on either side.

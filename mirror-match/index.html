Mirror Match — Support

Thanks for playing Mirror Match, a two-board sliding merge puzzle played with one swipe. One swipe moves both 4x4 boards at once, and the right-hand board is drawn as a mirror, so a sideways swipe pushes the two apart while an up or down swipe moves them together. Tiles merge only with the same stamp at the same rank; the way you get space back is Resonance, which clears both boards at once when matching tiles sit at positions that mirror each other across the seam. The tile you are dealt is always the same on both sides and only the cell it lands in differs, so a run is decided by where you put things rather than by what you drew. The run ends the moment one board is full with no merge left in it.
